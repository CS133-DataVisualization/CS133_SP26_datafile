# SJSU CS 133
This repository contains data files and colab notebooks for the CS 133 Data Visualization course at San Jose State University.

**Usage message to students** <br>
It is recommended that you **clone** this repository so that you can easily access the files in this repository. Since I will be updating the repository over the semester, some of the older files currently in the repository may be updated or remove. It is recommended that you do a `git pull` at the beginning of each class to get the updated file.

Once you do a  `git pull` of the repository, move the file to a working folder on your local machine or Google drive. This prevent overwrite of the files the next time you do another `git pull`.

You do not need to fork this repository as you will not be submitting (`git push`) your code to this repository but to the classroom repository. 


HAPPY CODING :)
